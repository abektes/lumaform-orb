# Archived engines

These factories were on disk but never in the catalog — no `ENGINE_TYPES` id, no schema, no presets, no `registerEngine` call.

- `mycelium-engine.js` — replaced by Chromasphere; it competed with Filament, Curl Drift, and Echo Rings
- `astrolabe-engine.js` — brief still in `docs/engine-briefs/astrolabe.md`; never catalogued
- `helios-engine.js` — brief still in `docs/engine-briefs/helios.md`; never catalogued
- `cymatics-engine.js` — no brief; never catalogued

Do not import these from `packages/`. To revive one, give it a catalog entry — see [docs/ENGINE-AUTHORING.md](../../docs/ENGINE-AUTHORING.md).
